DDL: Data Definition Language / any SQL statements that define the schema, so:
CREATE TABLE, CREATE INDEX, DROP TABLE etc.
DML: Data Manipulation Language, so think INSERT / UPDATE / DELETE statements... Anything manipulating existing data in your database system.

Predicate : This is typically referring to the WHERE clause of a query, essentially meaning the constraints we are putting on our query which will filter the resulting output.
